# Examples

Reference examples and inspiration assets used to inform Griot's design and architecture (the Foundrie kit keeps the same folder for the same purpose).

## What goes in here

- Landing-page / design inspiration screenshots influencing the **Public shell** (Awwwards-grade).
- Reference UI patterns for **Kanban boards**, **task detail modals**, **comment threads**, **notification feeds**.
- Architecture diagrams from other projects used as *input* to the design conversation (never as the final artifact — approved artifacts live in `../diagrams/`).

## Naming

`<topic>-<source>.{png,jpg,webp}` — e.g. `kanban-inspiration-awwwards1.png`. Keep a one-line note in this README when you add files.
